# Security Policy

This repository contains only my GitHub profile README, static banner assets, and a scheduled workflow that refreshes a list of blog links. There is no application code, no releases, and no supported versions.

## Reporting a vulnerability

If you find something sensitive in this repository, or a security issue in any of my other repositories:

- Email **adam@matthewsteinberger.com**, or
- Open a **private security advisory** on the affected repository (Security → Advisories → Report a vulnerability).

I'll acknowledge within a few business days. Please don't open a public issue for security reports.
